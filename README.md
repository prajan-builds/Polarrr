# Polarrr ✳

A tiny browser-based Polaroid photo studio. Upload a picture, choose a frame and photo effect, add a caption/date, and export a PNG.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Features

- Local photo upload and drag-and-drop
- Classic, soft, dark, and iPhone-inspired frames
- Caption, date stamp, font, text colour, and adjustable tilt
- Original, golden, black-and-white, vintage, cool, soft, moody, 8-bit, and oil-pastel-inspired effects
- Live preview and PNG export
- Responsive layout

Photos are processed in the browser and are not uploaded to an application server.

## Stack

Next.js, React, TypeScript, and CSS. The PNG export uses the browser Canvas API.
